# Name glossary

One table per series. Add each new name the day the character, place or skill first appears, then paste the "Exact spelling" column into rule 3 of the [recap script prompt](recap-script-prompt.md) for every chapter.

OCR misreads names (`Kae1en` for `Kaelen`), and a model may "fix" a misread name differently in each chapter. The glossary keeps one spelling for the whole series.
